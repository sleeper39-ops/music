# 🎸 Music Room — ห้องซ้อมดนตรีออนไลน์ & Live Jamming Studio

**Music Room** ระบบห้องซ้อมดนตรีและแจมเพลงสดออนไลน์แบบ **Ultra-Low Latency (WebRTC Peer-to-Peer)** พัฒนาด้วย Python Flask Single-File พร้อมอินเทอร์เฟซสไตล์ Music Studio & Audio Workstation (DAW) มืด-นีออน ล้ำสมัย สวยงาม ใช้งานได้จริงทั้งบน PC, Mac, iPhone, iPad และ Android

---

## ✨ คุณสมบัติและฟีเจอร์เด่น (Features)

1. 🎸 **รองรับการต่อ "เครื่องดนตรีจริง" (Real Instruments & Audio Interface)**:
   - **โหมดเสียงเครื่องดนตรี (Hi-Fi Studio Mode)**: ปิดระบบ Echo Cancellation, Noise Suppression และ AGC ของเบราว์เซอร์ เพื่อให้เสียงกีตาร์ เบส คีย์บอร์ด และกลองไฟฟ้า ส่งผ่านแบบ Stereo 48kHz เต็มย่านเสียงโดยไม่ถูกตัดทอนความถี่
   - **โหมดไมค์พูดคุย (Voice Mode)**: เปิดตัวกรองเสียงสะท้อนสำหรับการสนทนาทั่วไป
   - ใช้งานร่วมกับ Audio Interface (Focusrite Scarlett, Motu, Behringer ฯลฯ) หรือแจ็คต่อเสียงเข้าคอม / iPhone / iPad ได้ทันที

2. ⚡ **Ultra-Low Latency Live Jam (ดีเลย์ต่ำที่สุด)**:
   - ส่งข้อมูลเสียงและภาพตรงระหว่างผู้เล่น (Direct WebRTC P2P Mesh) ไม่ผ่านการแปลงเสียงซ้ำที่ Server
   - ปรับแต่ง Opus Codec บิตเรตสูงถึง 256kbps Stereo

3. 📷 **เปิดกล้องวิดีโอ & แชร์หน้าจอ/โน้ตเพลง (Video & Screen Share)**:
   - เปิดกล้อง Webcam หรือกล้องมือถือ/iPad ร่วมกับเพื่อนในวง
   - แชร์หน้าจอโปรแกรมทำเพลง (DAW: GarageBand, Logic, Ableton, FL Studio, Cubase) หรือแชร์แท็บ/คอร์ดเพลง

4. 🔴 **บันทึกวิดีโอ & เสียงการซ้อมสด (Live Studio Session Recorder)**:
   - มิกซ์เสียงทุกคนในห้องซ้อม + สตรีมวิดีโอ เข้าเป็นไฟล์เดียวกันสดๆ ผ่าน Web Audio & MediaRecorder
   - ดาวน์โหลดไฟล์การซ้อม (`.webm` / `.mp4`) เก็บไว้ฟังหรือตัดต่อได้ทันที

5. ⏱️ **เครื่องเคาะจังหวะ Metronome ซิงค์ห้อง & Tap Tempo**:
   - ปรับ Tempo BPM (40 - 240 BPM) พร้อมระบบนับจังหวะ Accent
   - ปุ่ม Tap Tempo เคาะหาจังหวะเพลงที่ต้องการ

6. 🎯 **เครื่องเทียบเสียงมาตรฐาน (A440 & Guitar/Bass Tuner)**:
   - มีเสียงความถี่มาตรฐานสากล A440 และเสียงเทียบสายกีตาร์ E2, A2, D3, G3, B3, E4

7. 💬 **แชทสด & ตัวช่วยแทรกคอร์ด (Live Chord Chat)**:
   - พิมพ์พูดคุยในห้องซ้อม
   - มีปุ่มคอร์ดลัด `[C] [Dm] [Em] [F] [G] [Am]` ไฮไลต์สีคอร์ดอัตโนมัติ
   - แนบภาพ แท็บเพลง หรือไฟล์เสียง Demo

8. 📱 **เชื่อมต่อมือถือ / iPad สะดวกด้วย QR Code**:
   - รองรับทั้งการเล่นในวง **Wi-Fi / LAN** เดียวกัน หรือเล่นระยะไกลผ่าน **Tailscale VPN**

## 🚀 วิธีการรันโปรแกรม

### 1. ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### 2. รันเซิร์ฟเวอร์ห้องซ้อม
```bash
python chat_app.py
```

เมื่อรันสำเร็จ โปรแกรมจะแสดงที่อยู่ IP สำหรับเชื่อมต่อ:
```text
============================================================
 🎸 Music Room — Live Jam Studio กำลังทำงานบนเซิร์ฟเวอร์...
 🌐 สำหรับเครื่องนี้: http://127.0.0.1:5000
 📱 สำหรับมือถือ/iPad/เครื่องอื่น [Wi-Fi / LAN]: http://192.168.1.50:5000
 📱 สำหรับมือถือ/iPad/เครื่องอื่น [Tailscale VPN]: http://100.x.x.x:5000
============================================================
```

## 🔌 คำแนะนำในการต่อเครื่องดนตรีจริง (Pro Audio Tips)

1. **การต่อเข้าคอมพิวเตอร์ (PC / Mac)**:
   - เสียบกีตาร์ / เบส / คีย์บอร์ด / กลองไฟฟ้า เข้าที่ **Audio Interface**
   - ในระบบ Music Room ให้เลือก **"🎸 เครื่องดนตรีจริง (Hi-Fi)"** (ปุ่มมุมขวาบน)
   - สวม **หูฟัง (Headphones)** เสมอ เพื่อป้องกันเสียงจากลำโพงวนกลับเข้าไมค์
2. **การต่อเข้า iPhone / iPad**:
   - ใช้สายแปลง Lightning/USB-C เข้า Audio Interface หรือ iRig / แจ็คแปลงสัญญาณ
   - เปิดเบราว์เซอร์ Safari / Chrome แล้วสแกน QR Code เพื่อเข้าห้องซ้อมได้ทันที

- **สร้างห้องสาธารณะ**: ไม่ต้องตั้งรหัสผ่าน สมาชิกในเครือข่ายสามารถกดเข้าร่วมได้ทันที

- **ผู้สร้างห้อง (Admin)**: มีสิทธิ์ในการลบห้องซ้อมเมื่อซ้อมเสร็จสิ้น
